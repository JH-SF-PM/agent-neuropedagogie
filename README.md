# Agent Formateur en Neuropédagogie

Agent expert basé sur le SDK Mistral Agents pour aider les formateurs à analyser leurs vidéos de formation et améliorer leurs sessions.

## Fonctionnalités

- Analyse de vidéos de formation
- Création de quiz pédagogiques
- Évaluation des 4 piliers de l'apprentissage
- Recommandations d'outils interactifs

## Déploiement

```bash
uv pip install mistralai-agents
uv run agents deploy
```
